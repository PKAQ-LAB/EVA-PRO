所有真实路由的列表表格填满可用内容高度并适配分辨率；分页固定在页面页脚上方，表格内部滚动，数据行保持自然密度。

## 验收要求

空态、少量数据、大量数据和加载状态布局稳定；分页和工具栏不跟随表体纵向滚动，横向滚动条在表体底部；搜索换行、提示出现和窗口变化重算可用空间。覆盖常见桌面宽高和窄屏，极低可用高度保留可达操作，不靠固定100vh减去魔数。实际组件几何、用户现场反馈、自动化测试与静态检查分别报告。
